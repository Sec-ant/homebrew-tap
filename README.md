# Sec-ant's Homebrew tap

Install [cinekey](https://github.com/Sec-ant/cinekey), a parser for movie and TV
release names:

```sh
brew install sec-ant/tap/cinekey
```

The formula installs the published binary for macOS or Linux on ARM64 and x86-64,
with SHA-256 verification. The executable is named `cinekey`.

Update through Homebrew:

```sh
brew update
brew upgrade cinekey
```

Stable cinekey releases update the formula automatically. Release artifacts and
checksums are available from [GitHub Releases](https://github.com/Sec-ant/cinekey/releases).
