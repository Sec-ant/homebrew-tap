# Sec-ant's Homebrew tap

Homebrew formulae for command-line tools maintained by [Sec-ant](https://github.com/Sec-ant).

## Available tools

| Tool | Description | Install |
| --- | --- | --- |
| [cinekey](https://github.com/Sec-ant/cinekey) | Parse movie and TV release names | `brew install sec-ant/tap/cinekey` |

## Install and update

Install a tool with `brew install sec-ant/tap/<name>`, for example:

```sh
brew install sec-ant/tap/cinekey
```

Update an installed tool through Homebrew:

```sh
brew update
brew upgrade cinekey
```

Downloads are verified with SHA-256. Each tool's release process maintains its
formula in `Formula/<name>.rb`.
